# Video Score Reconstruction

> **Reconstruir automaticamente grades musicais a partir de performances audiovisuais, integrando visão computacional, processamento de áudio, transcrição musical e representação simbólica para gerar MusicXML e partituras instrumentais em PDF.**

## Objetivo Central

Desenvolver uma aplicação computacional capaz de reconstruir, a partir de vídeos de performances musicais que apresentam e executam uma grade musical, uma representação simbólica estruturada da obra, integrando informações visuais e acústicas para gerar automaticamente a grade musical em MusicXML e, a partir dela, as partituras individuais dos instrumentos em formato PDF.
