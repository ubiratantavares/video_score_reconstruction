# Visão do Projeto

## Propósito
Conectar o registro audiovisual de performances musicais à representação simbólica formal.

## Visão
Ser a ferramenta padrão para reconstrução multimodal automatizada de grades musicais a partir de vídeo.

## Problema
Transcrições unimodais (só áudio) ignoram dados visuais cruciais. Transcrições manuais são lentas e suscetíveis a erro. Faltam soluções integradas.

## Solução
Aplicação multimodal (Visão + Áudio) para processar, alinhar temporalmente e reconstruir grades estruturadas (MusicXML) e extrair partes individuais (PDF).

## Público-Alvo
- Músicos e compositores.
- Pesquisadores em MIR (Music Information Retrieval) e OMR.
- Arquivistas musicais.

## Valor Produzido
- Otimização do tempo de transcrição.
- Resgate estrutural de obras sem partitura.
- Base arquitetural para evolução de modelos de IA musical.
